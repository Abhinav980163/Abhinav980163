### 👋 About Me

QA Engineer whose core is **test design, database batteries, CI regression gates, and PR review**. I work *executed-not-asserted* — I break a thing on purpose and watch it fail before I trust the guard against it. My value is catching the wrong count or the missed detail before it ships, not waving it through.

I don't approve software — I try to break it, and document exactly how. Every guard I build is proven by breaking what it protects and watching it catch the failure.

---

### 🏗️ What I've Built

- 🚦 **Deterministic pre-merge regression gate** — boots the app on an ephemeral database and drives real request paths, asserting the database write **and** the outbound reply, so a red is a real defect, never flake.
- 🗄️ **Schema-level database batteries** — real-schema PostgreSQL checks that verify stored *values*, not just row counts ("the reply said 21:15 — the DB stored 15:00").
- 🎯 **Kill-check / mutation discipline** — every guard is proven by breaking its subject on purpose and watching it red, then recording the evidence in the artifact.
- 🔍 **PR review** — reading diffs across the team and catching contract drift before merge.
